# Site generator

The website's HTML pages are generated by these Python scripts, so the header, footer, SEO tags and structured data stay identical on every page.

| File | What it builds |
|---|---|
| `layout.py` | Shared `<head>` (SEO, schema, GSAP), header + services dropdown, footer, chat |
| `pages.py` | Home, Services, Pricing, Our Work, Team, About/Contact, Start a project, 404 |
| `landing.py` | Gorakhpur service landing pages (video editing, social media, Reels, ads, design, local SEO) |
| `blog_posts.py`, `blog_more.py` | Blog index and articles |
| `seo_files.py` | `sitemap.xml` and `llms.txt` |

## Story order (chapters)

Pages are told as one story. The order, chapter names and the "Next chapter" links come from `CHAPTERS` in `layout.py`
(Home → Services → Our Work → Pricing → Team → About → Start a project → Blog → Home). Service landing pages lead to Pricing,
and each blog post leads to the next post. Page transitions and all GSAP animations live in `assets/js/motion.js`.

## Rebuild after editing content

Run from the project root (`D:\ouredgemedia`):

```powershell
$env:PYTHONPATH = "_generator"; python _generator/pages.py; python _generator/seo_files.py
```

## Add a blog post

Add a new entry at the top of `NEW_POSTS` in `blog_more.py` (copy an existing one, change `slug`, `date`, `title`, text and FAQs), then rebuild. It is added to the blog, related posts, sitemap and llms.txt automatically.

Note: editing a generated `.html` file directly works, but the change is overwritten the next time the generator runs.
